# One Line, One Chill

A single-sentence horror entry built around a rescue that arrives too late for the wrong reason. The dread comes not from what the searchers find, but from the moment a familiar signal goes silent and the silence itself becomes the explanation.

The program is deliberately minimal: it holds one carefully worded sentence, checks its length, and writes it out exactly the same way on every run.

## Run

```bash
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```
